# Personal Portfolio Dashboard – React Router

## Description

A React-based Personal Portfolio Dashboard demonstrating client-side routing and nested routes using React Router.

## Pages

- `/` - Home
- `/about` - About
- `/contact` - Contact
- `/dashboard` - Dashboard
- `/dashboard/profile` - Profile
- `/dashboard/settings` - Settings

## Features

- Client-side navigation using React Router
- Navigation bar available across the application
- Contact form with `preventDefault()`
- Programmatic navigation using `useNavigate()`
- Nested Dashboard routes
- Dashboard layout using `Outlet`

## Technologies Used

- React
- React Router DOM
- JavaScript
- Vite
